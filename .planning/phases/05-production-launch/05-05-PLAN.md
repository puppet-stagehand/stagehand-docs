## Flagged Assumptions (edge-probe fallback, LAUN-02)

The spec-less edge-probe fallback surfaced two generic categories for LAUN-02:

- **empty** ("what is the result for empty/single-element/null input?"): the redirect function's
  handling of the root path (`uri == "/"`) and of a URI with no extra segments is already covered
  by `redirect.test.mjs`'s existing "disabled apex behavior" and "trailing-slash" test cases (GATE-05
  wires these into `verify`, Plan 05-04) — this plan introduces no new path-handling logic, so no
  new empty-input case exists to resolve here.
- **encoding** ("whose definition of length/equality applies?"): the redirect's host comparison
  (`request.headers.host.value.toLowerCase() === 'puppetstagehand.com'`) is a plain ASCII
  case-insensitive string compare against a fixed literal — `puppetstagehand.com` is an ASCII-only
  domain with no IDN/Unicode variant, so no encoding-normalization question applies. This is
  existing, already-tested code this plan does not modify.
</flagged_assumptions>
