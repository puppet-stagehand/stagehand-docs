<objective>
Close INFRA-06: move the bootstrap root's inline tag literals onto the shared `required_tags` local
introduced in plan 01-01, and extend `scripts/check-tofu-tags.sh` so the bootstrap root is covered by
the same policy gate the environment roots and the static-site module already have.

OpenTofu directory in the repository whose tags nothing checked. A tag policy that covers everything
except the most sensitive root is a policy with a hole in exactly the wrong place.

message in `scripts/check-tofu-tags.sh`. Both pre-existing tag regression runs stay green.
