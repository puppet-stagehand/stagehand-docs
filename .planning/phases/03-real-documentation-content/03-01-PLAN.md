## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Content author (git PR) -> rendered public HTML | Markdown in `src/content/docs/` is committed by a reviewed PR and rendered verbatim by Astro's content-collection pipeline into public-facing HTML. |
| `scripts/deploy-site.sh` invalidation list -> CloudFront cache | A route present in the built output but absent from the invalidation `--paths` list can be served stale to visitors after a deploy. |
